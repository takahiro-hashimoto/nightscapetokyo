---

## 重要な前提（必ず守る）

- これは **Skylum公式ストアのスクリーンショットではなく、独自の解説図** です。
  公式サイトのUI・レイアウト・ロゴを模倣・再現しないこと。
  ブラウザのウィンドウ枠、URLバー、公式サイトのボタン意匠なども描かないこと。
- 一目で「解説用の図解」と分かるフラットなインフォグラフィックにすること。
- Skylum / Luminar のロゴは使用しない。テキストで「Luminar」と書くのは可。

---

## デザインルール

- 全体：フラットデザインのインフォグラフィック。立体感・光沢・ドロップシャドウは控えめ
- 背景：明るいライトグレー `#f4f6f9` の無地
- カード：白 `#ffffff`、角丸16px、境界線 `#e2e8f0` 1px
- フォント：日本語ゴシック体。見出しは太字
- 余白を広めに取り、3枚のカードを横並びに均等配置
- 装飾は最小限。イラスト調のキャラクターや写真は入れない

## カード内容（左から順に）

各カードの構成は上から「プラン名 → デバイス → 価格 → 一言」。
**表示する価格は通常価格（定価）のみ。** セール価格や取り消し線は入れないこと。
セール価格は時期によって変わるため、図に入れると短期間で古くなる。

## 下部の注釈（1行）

カードの下に小さく（24px前後、色 `#718096`）：

```
※通常価格。セール時はここから割引されます
```

日付を入れないこと。通常価格は頻繁には変わらないため、
日付を書かないほうが図の寿命が長くなる。

## 雰囲気

購入前の人が「3つあって、それぞれこう違うのか」と2秒で理解できること。
価格比較表として機能する、清潔で読みやすいトーン。
広告的な煽り（爆安！今だけ！のような表現）は入れない。
